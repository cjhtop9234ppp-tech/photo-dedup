# 03. 설치 및 실행 방법 (새 PC 기준)

## 방법 A — GitHub Release 설치 파일 사용 (가장 쉬움)

```text
GitHub 저장소(https://github.com/cjhtop9234ppp-tech/photo-dedup)
↓
Releases 탭 → v1.0.0
↓
Assets에서 PhotoDedup_Setup_1.0.0.exe 다운로드
↓
실행 → 설치 마법사 진행
   (원하면 "탐색기에서 zip 파일 우클릭 시 ... 메뉴 추가" 체크)
↓
시작 메뉴 / 바탕화면 바로가기로 실행
```

> 저장소가 **Private**이므로, GitHub 계정으로 로그인한 상태에서만 Releases 페이지와 Asset
> 다운로드가 가능합니다(협업자로 초대되지 않은 계정은 접근 불가) — `확인 필요`: 실제 접근 권한
> 부여 범위는 GitHub 저장소 설정(Collaborators)에서 별도로 관리해야 합니다.

## 방법 B — 소스코드 실행 (개발자용)

```bash
git clone https://github.com/cjhtop9234ppp-tech/photo-dedup.git
cd photo-dedup
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 필요한 환경

| 항목 | 내용 | 근거 |
|---|---|---|
| OS | Windows 10/11 (x64) | `installer.iss` `ArchitecturesInstallIn64BitMode=x64compatible` |
| Python | 3.11 권장(3.9~3.12 대체로 동작, exe 빌드는 3.11 기준 검증) | 개발 시 `python --version` 확인 기록 |
| 필요 프로그램(설치파일 빌드 시) | Inno Setup 6 — `winget install JRSoftware.InnoSetup` | `build.bat`, `README.md` |
| 필요 라이브러리 | `requirements.txt`: Pillow, imagehash, tkinterdnd2, send2trash, pyinstaller | 직접 확인 |
| 선택 프로그램 | FastStone Image Viewer(없어도 정상 동작, 자동으로 탐색기 대체) | `app/gui.py` `find_faststone_exe()` |

## 초기설정

**초기설정 절차가 없습니다.** 환경변수, API 키, 설정 파일이 전혀 필요 없는 프로그램이라
설치(또는 `pip install`) 후 바로 실행하면 됩니다 — [[04_설정값_환경변수]] 참고.

## exe / 설치 프로그램 직접 빌드

```bash
venv\Scripts\activate
pip install -r requirements.txt
build.bat
```

`build.bat` 내부 명령:

```bash
pyinstaller --noconfirm --onefile --windowed --name PhotoDedup ^
    --collect-all tkinterdnd2 ^
    --collect-all imagehash ^
    main.py

"%LocalAppData%\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

## 정상 동작 확인

1. `python main.py` → GUI 창이 뜨는지 확인
2. 사진이 든 zip 선택 → "처리 시작" → 진행률바 확인
3. "결과 폴더 열기" → 순서 정리 창이 뜨는지 확인
4. 자세한 테스트 절차/기대값은 `REPRODUCTION_GUIDE.md`(저장소 루트) 8번 섹션 참고
