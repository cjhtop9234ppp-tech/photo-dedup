# 06. 유지보수 가이드 — "이 기능을 바꾸려면 어느 파일을 고쳐야 하나?"

## 중복 판정 기준 변경

```text
→ 담당 파일: app/core.py
→ 담당 함수: cluster_photos(), BKTree.query()
→ 함께 확인할 파일:
    - app/gui.py (threshold_var 슬라이더 0~20, 기본 5)
    - app/cli.py (--threshold 기본 5)
→ 주의: item.sha256은 계산만 되고 실제 비교에 쓰이지 않음(11_SKILL_역분석_MASTER.md 참고).
   "완전 동일 파일만 더 엄격히 잡고 싶다"는 요구라면 sha256 비교를 새로 추가해야 함(현재 없음).
→ 테스트 방법: 완전동일 2장+재압축 1장+고유 2장+비이미지+손상이미지가 섞인 zip으로 CLI 실행 후
   "고유 사진 수"가 예상과 맞는지 확인 (REPRODUCTION_GUIDE.md 8번 섹션에 스크립트/기대값 있음)
```

## 지원 이미지 확장자 변경

```text
→ 담당 파일: app/core.py
→ 설정: IMAGE_EXTENSIONS 상수
→ 테스트 방법: 해당 확장자 이미지를 zip에 넣고 "전체 사진 수"에 포함되는지 확인
   (Pillow가 그 포맷을 열 수 있어야 함 — .heic 등은 확인 필요)
```

## 사진 이동/삭제 방식 변경

```text
→ 담당 파일: app/gui.py
→ 담당 함수: OrderEditor._confirm()
→ 안전장치: 확정 전 messagebox.askyesno() 확인, 2단계 안전 리네임(임시이름 경유)
→ 주의: send2trash()를 os.remove()/shutil.rmtree()로 바꾸면 복구 불가능한 완전삭제가 됨
   — 절대 변경 금지 항목([[10_AI_HANDOFF]] 참고)
→ 테스트 방법: 확정까지 진행 후 원본 zip이 실제로 휴지통에 들어갔는지 확인
   (PowerShell Shell.Application COM으로 확인 가능)
```

## 자동 실행(zip 우클릭) 범위 변경

```text
→ 담당 파일: main.py (진입점 분기), app/gui.py (DedupApp.run_auto, main())
→ 함께 확인할 파일: installer.iss ([Registry] 섹션)
→ 주의: 자동화 범위를 "최종 결과폴더로 보내기"까지 넓히면 사람 확인 없이 파일명변경/삭제/
   zip이동이 일어나게 됨 — 설계 원칙과 정면 배치, 신중히 결정할 것
→ 테스트 방법: PowerShell Start-Process로 "<exe경로>" "<zip경로>" 형태로 직접 실행해
   실제 우클릭과 동일하게 재현 가능
```

## 설치 프로그램 옵션(Task) 추가/변경

```text
→ 담당 파일: installer.iss
→ 섹션: [Tasks], [Registry]/[Icons]/[Run](Tasks: 이름으로 연결)
→ 빌드 명령: "%LocalAppData%\Programs\Inno Setup 6\ISCC.exe" installer.iss
→ 테스트 방법: //VERYSILENT //TASKS="task이름" //DIR="테스트폴더" 로 격리 설치 후 확인,
   unins000.exe //VERYSILENT로 제거해 깨끗이 지워지는지 확인
   (Git Bash에서는 반드시 슬래시 두 개(//) 표기)
```
