## B. 분석 결과 제안하는 개선사항 (현재 없음, 새 제안)

> [!제안] 아래는 모두 제안이며, 실행 여부는 결정이 필요합니다.

1. **완전 동일 파일 우선 판정 추가** — `item.sha256`을 실제로 활용해 대용량 처리 시 선-필터링에
   쓸 수 있음(현재도 결과는 정확하지만 성능 개선 여지).
2. **로그 파일 저장 옵션(기본 꺼짐)** — 문제 재현/지원 목적. "바탕화면에 폴더 하나만" 원칙과
   충돌하지 않게 옵션으로만.
3. **지원 확장자 확대(.heic 등)** — Pillow의 HEIC 지원 여부 확인 필요.
4. **스크린샷/커스텀 아이콘 추가** — README/GitHub 저장소 품질 향상.
5. **GitHub Actions로 exe 빌드 자동화** — 태그 push 시 자동으로 Release 생성.
6. **대량 처리(수만 장) 실측 벤치마크** — 현재 실측 데이터 없음, 필요 시 개선 검토.

## 우선순위 (제안, 분석자 판단)

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | 스크린샷 추가 | GitHub 방문자 이해도에 직접적 영향, 난이도 낮음 |
