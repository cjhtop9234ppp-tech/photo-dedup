# 04. 설정값 · 환경변수

## 전체 결론

이 프로그램은 **환경변수(`.env` 등)를 전혀 사용하지 않습니다.** 설정 파일(`config.yaml`,
`settings.json` 등)도 없습니다. `os.environ`을 읽는 코드가 없습니다(전체 grep 결과 `environ`
미검출). API 키/비밀번호/토큰 등 Secret 값을 다루는 코드 자체가 없는 순수 로컬 프로그램입니다.

> 이 문서에는 실제 Secret 값을 기록하지 않았습니다(애초에 존재하지 않음).

## 코드 안 상수로 존재하는 설정값 (실제 있는 것만)

| 설정명 | 위치(파일) | 기본값 | 역할 | 변경 시 영향 |
|---|---|---|---|---|
| `IMAGE_EXTENSIONS` | `app/core.py` | `{".jpg",".jpeg",".png",".bmp",".gif",".webp"}` | 이미지로 취급할 확장자 | 없는 확장자(`.heic` 등)는 추출조차 안 됨 |
| `phash_threshold` | `app/core.py` `process_zips` 파라미터 | 5 | pHash 판정 임계값 | 낮을수록 엄격, 높을수록 느슨. GUI 슬라이더 0~20 |
| `allow_rotate_flip` | `app/core.py` 파라미터 / GUI 기본값 | GUI 기본 켜짐(True) | 회전·반전 변형도 중복으로 볼지 | 켜면 회전/반전 사진도 같은 그룹으로 묶임 |
| `THUMB_SIZE` | `app/gui.py` | `(110, 110)` | 중복 미리보기 팝업 썸네일 크기 | UI 표시 크기만 영향 |
| `OrderEditor.THUMB_SIZE` | `app/gui.py` | `(150, 150)` | 순서 정리 창 썸네일 크기 | 열 개수 계산에도 사용됨 |
| `OrderEditor.COLUMNS_MIN` | `app/gui.py` | 3 | 최소 열 개수 | 창이 좁아도 최소 3열 유지 |
| 파일 선택 기본 경로 | `app/gui.py` `_on_pick_files` | `str(Path.home() / "Downloads")` | "파일 선택" 클릭 시 기본 폴더 | **계정 독립적** — 어떤 PC/계정에서도 그 계정의 다운로드 폴더를 자동으로 찾음(없으면 `Path.home()`) — 이전에는 특정 계정 경로가 하드코딩돼 있었으나 GitHub 공개 전에 일반화함 |
| FastStone 경로 후보 | `app/gui.py` `_FASTSTONE_COMMON_PATHS` | 2개 표준 설치 경로 | 결과 폴더 확정 후 열어줄 뷰어 탐색 | 이 경로 + 레지스트리 App Paths까지 확인, 없으면 탐색기로 대체 |
| `installer.iss` `AppId` | `installer.iss` | `{8F1E9C2E-7B3A-4C5D-9E1F-2A6B8C4D7E10}` | 설치 프로그램 식별 GUID | 바꾸면 기존 설치본과 별개 프로그램으로 인식됨 — **절대 임의 변경 금지** |
| `installer.iss` `MyAppVersion` | `installer.iss` | `"1.0.0"` | 버전 표시 | Release 태그(`v1.0.0`)와 맞춰서 관리 |

## API 관련 설정

**없음.** 이 프로그램은 외부 API를 호출하지 않습니다(네트워크 호출 코드 자체가 없음, 전체 프로젝트
`requests`/`urllib`/`socket`/`http` 검색 결과 0건).

## 실행 시 매번 새로 계산되는 값

| 값 | 계산 방식 | 위치 |
|---|---|---|
| 바탕화면 실제 경로 | `winreg`로 `HKCU\...\Shell Folders`의 `Desktop` 값 조회(OneDrive 리다이렉트 대응) | `app/core.py` `get_desktop_path()` |
| 결과 폴더명 | `결과_유니크사진_` + 실행 시점 타임스탬프 | `app/core.py` `process_zips()` |
